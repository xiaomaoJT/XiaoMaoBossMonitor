# 本地配置目录

这个目录放**这一家的**配置：真实拉流地址、推送凭据、白名单、摆放坐标。
它不是软件的一部分 —— 软件本身只带一份空白的默认配置，谁拿到安装包都没有你的凭据。

## 怎么用

1. **载入**：设置 → 配置方案 → **载入本地配置文件** → 选这个目录里的 `.json`。
   载入后点「保存并应用」才真正生效（载入只填表单，不写存档）。
2. **导出/备份**：设置 → 配置方案 → **导出配置**，存出来的就是同样格式的文件。
3. **换机器**：把 `.json` 拷过去，在新机器上载入即可，不必手抄任何地址或密钥。

## 文件约定

| 文件 | 进版本库？ | 说明 |
|---|---|---|
| `config.example.json` | ✅ 进 | 格式示例，全是占位值，用于说明每个字段长什么样 |
| `hidden-config.local.json` | ❌ 不进 | 真实配置（`.gitignore` 已排除 `config/*.json`） |
| 其它 `*.json` | ❌ 不进 | 导出备份、临时改法都放这里，一律不入库 |

## 注意

- 载入**只补缺**：文件里没写的字段取默认值；写了的字段按文件来。
  所以"只写 3 个通道 + 只有钉钉凭据"是一份合法配置。
- 文件里没有的凭据**不会**用软件里的值去填 —— 软件里本来就没有。
- 这份文件等于凭据本体。丢了就只能去平台重置机器人；泄漏了同样要去重置。
